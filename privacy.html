Privacy policy

TrueScope Uploader · last updated 4 October 2026

What this app is

“TrueScope Uploader” is a private tool used only by the owner of the TrueScope YouTube channel (@truescopegta). It uploads and schedules the channel’s own videos, edits their titles and descriptions, and reads the channel’s own YouTube statistics. It is not offered to the public, and no one else signs in to it.

Data it uses

With the channel owner’s permission, granted through Google’s sign-in screen, the app accesses the owner’s own YouTube channel through the YouTube Data API and the YouTube Analytics API (read-only). Through the YouTube Data API it can upload and schedule videos and change the title, description, tags and visibility of the channel’s own videos, and it reads video titles, publishing status and view, like and comment counts. Through the YouTube Analytics API it reads aggregate numbers for the channel’s own videos, such as views, watch time and subscribers gained. These are aggregate numbers, not information about individual viewers.

How data is used and stored

The numbers and the sign-in token are used only to plan, publish and improve the channel’s own videos. They are stored only on the channel owner’s own computer. The owner runs automation scripts and an AI assistant on that computer to read the numbers and prepare videos, and these act only on the owner’s behalf. The data is not sold, not used for advertising, not published, and not shared with anyone else.

Keeping and deleting data

Data stays on the owner’s computer until the owner deletes it. Revoking the app’s access (see below) makes the sign-in token stop working, and deleting the stored token file removes the app’s ability to access the account until the owner signs in again.

Google and YouTube

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service, and Google’s handling of your data is described in the Google Privacy Policy. The app’s use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account page myaccount.google.com/permissions.

Visitors to this website

This website does not use cookies, analytics or tracking, and does not collect any information about visitors. It is hosted on GitHub Pages, which may keep its own server logs.

Children
